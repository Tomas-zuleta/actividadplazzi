#  Sitio Web Estático Inspirado en Platzi

##  Descripción

Este proyecto consiste en el desarrollo de un **sitio web estático** inspirado en la plataforma educativa **Platzi**, diseñado con una interfaz moderna en modo oscuro y una experiencia de navegación intuitiva.

El sitio permite explorar diferentes secciones relacionadas con la educación en línea mediante una estructura clara y un diseño responsivo.

---

##  Características

*  Diseño moderno con tema oscuro.
*  Paleta de colores en tonos verdes y gradientes.
*  Diseño responsivo para diferentes dispositivos.
*  Navegación entre múltiples páginas.
*  Interfaz limpia y consistente inspirada en plataformas de aprendizaje.

---

## Secciones del sitio

* 🏠 Inicio
* 📚 Rutas de aprendizaje
* 🎓 Educación
* 👥 Colaboradores
* 💳 Planes
* 🔐 Login

## Objetivo

El objetivo principal de este proyecto fue fortalecer el trabajo colaborativo en un entorno de desarrollo de software mediante el uso de Git y GitHub como herramientas de control de versiones. Como producto de este proceso, el equipo diseñó y desarrolló un sitio web estático inspirado en Platzi, aplicando principios de diseño responsivo, organización del código y colaboración entre desarrolladores para integrar los aportes de cada integrante de manera eficiente.
